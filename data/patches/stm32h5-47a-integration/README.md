# H5E/F 正式集成依据

本包固定 24 个准确型号的组合候选及其原始基线。
PAC 的 5 个既有文件、HAL 的 10 个既有文件保存旧内容，其余旧文件直接复用，
避免复制整套后端。文件清单要求发布前后均为完整状态，拒绝部分发布或本地改动。

补丁顺序为原始后端 → H543/H553 → G0 UCPD（HAL）→ H5E/F。
逆向恢复按相反顺序执行。原始 H5E/F PAC 候选清单保留为 pac-candidate-manifest.json；
正式来源包增加 24 份与 inputs.zip 字节一致的芯片 JSON，供既有目录生成器使用。
本包准备依据包括 38 个最小固件、216 个外设固件和固定生成器重建结果。
这些均为编译链接与主机验证；硬件行为未据此标记通过。
